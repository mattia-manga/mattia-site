SITO PERSONALE — MATTIA MANGANIELLO

COME APRIRLO
1. Estrai la cartella.
2. Apri index.html con Safari, Chrome, Edge o Firefox.

FILE PRINCIPALI
- index.html  -> contenuti e struttura
- style.css   -> grafica e responsive design
- script.js   -> menu mobile e anno automatico

DA PERSONALIZZARE
Nel file index.html, nella sezione Contatti:
- sostituisci inserisci-la-tua-email@example.com con il tuo indirizzo email;
- sostituisci href="#" del pulsante LinkedIn con l'URL del tuo profilo LinkedIn.

PUBBLICAZIONE
La cartella può essere pubblicata direttamente su GitHub Pages, Netlify,
Cloudflare Pages o Vercel senza build o dipendenze.
